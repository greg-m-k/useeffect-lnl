The order placed twice

A checkout form records that the user submitted, and something has to place the order. Event logic in an effect places it whenever submitted is true, so it runs again each time the form mounts with submitted still true, for example after the user navigates away and back. Event logic in the handler places it once, on the click. The server counts the orders it receives from you. New to these terms? Start here.
